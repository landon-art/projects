Particles met so far

  • は wa: topic marker. Written ha, read wa.
  • の no: "of", links two nouns. Kanada no shusshin = origin of Canada.
  • か ka: sentence-final question marker.
  • から kara: from.

Respect prefixes

お / ご o- / go- before a noun makes it about the listener respectfully: o-shigoto (your work), go-shusshin (your origin). Use them when asking, drop them when answering about yourself.

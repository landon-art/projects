Glossary

Terms used across all lessons. Use these exact words.

TermMeaning
Hermes AgentNous Research's self-hosted LLM agent runtime. Owns ~/.hermes.
TickOne scheduled firing of a cron job.
Pre-run script (gate)Program run before the LLM each tick. Its last stdout line can cancel the LLM run.
wakeAgentJSON key on the gate's last stdout line. Only strict false skips the LLM.
Fail-openAmbiguous gate output wakes the agent. Cost over silence.
Silent tickA tick where the gate closed: no LLM, no delivery, log only.
[SILENT] markerString in the LLM's final response. Suppresses delivery of a successful run.
DeliverySending the run's output to the configured channel (chat, etc.).
SkillA SKILL.md with frontmatter, loaded into context before the prompt. Attachable to cron jobs.
SOUL.mdAgent identity file. System-prompt slot #1 in every run.
ProfileIsolated ~/.hermes/profiles/<name> with own SOUL, skills, cron, config.

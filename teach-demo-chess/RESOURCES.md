# Chess Openings Resources

## Knowledge

- [Article: "Chess Opening Principles" by NM Dane Mattson (Chess.com)](https://www.chess.com/article/view/learn-chess-opening-principles)
  Six principles: control the centre, develop, protect the king, active pieces, watch the opponent's move, game phases. Use for: the core principle set every lesson refers to.
- [Article: "The 10 Most Common Mistakes Among Chess Beginners" by FM Luis Fernandez Siles (Chess.com)](https://www.chess.com/article/view/the-10-most-common-mistakes-among-chess-beginners)
  Opening mistakes 1 to 3: too many pawn moves, early queen, king left in centre. Use for: naming what goes wrong in a lost game.
- [Lessons: "Opening Principles" (Chess.com, interactive)](https://www.chess.com/lessons/opening-principles)
  Interactive drills on the same principles. Use for: extra practice after lesson 0001.
- [Study: "Basic opening principles" (Lichess)](https://lichess.org/study/ZTYzV6Jl)
  Free, board-based walkthrough. Use for: seeing the principles played out on a live board.
- [Article: "How to Defend Against Scholar's Mate" (ChessAtlas)](https://chessatlas.net/blog/opening-theory/how-to-defend-against-scholars-mate-beat-the-4-move-checkmate-every-time)
  Exact defensive move order ...Nc6, ...g6 or ...Qe7, ...Nf6 and the ...g6-first pitfall. Use for: lesson 0002.
- [Encyclopedia: "Scholar's mate" (Wikipedia)](https://en.wikipedia.org/wiki/Scholar%27s_mate)
  Neutral reference for the mating pattern and its variants. Use for: cross-checking move sequences.

## Wisdom (Communities)

- [r/chessbeginners](https://reddit.com/r/chessbeginners)
  Beginner-only subreddit; post a lost game link and ask "where did I go wrong?". Use for: game reviews from humans.
- [r/chess "No Stupid Questions" threads](https://reddit.com/r/chess)
  Larger, recurring Q&A threads. Use for: rules and principle questions.
- Lichess game analysis (free engine review after each game)
  Use for: finding the exact move where the game was lost. Post that move to a community.

Subnetting (1.6) runs as a daily 10-minute drill from week 1 to exam day. It is the single skill most cited in r/ccna failure posts. Anki review is daily from week 1.

1.0 Network Fundamentals 20% · weeks 1–3

#ObjectiveWeek
1.1Explain role/function of network components: routers, L2/L3 switches, NGFW and IPS, APs, controllers, endpoints, servers, PoE1
1.2Topology architectures: two-tier, three-tier, spine-leaf, WAN, SOHO, on-prem and cloud1
1.3Physical interfaces and cabling: single-mode/multimode fiber, copper; shared media vs point-to-point1
1.4Identify interface and cable issues: collisions, errors, duplex/speed mismatch1
1.5Compare TCP to UDP2
1.6Configure and verify IPv4 addressing and subnetting2 + daily
1.7Describe private IPv4 addressing2
1.8Configure and verify IPv6 addressing and prefix3
1.9IPv6 address types: global/unique-local/link-local unicast, anycast, multicast, modified EUI-643
1.10Verify IP parameters on client OS (Windows, macOS, Linux)3
1.11Wireless principles: nonoverlapping channels, SSID, RF, encryption3
1.12Virtualization fundamentals: server virtualization, containers, VRFs3
1.13Switching concepts: MAC learning/aging, frame switching, flooding, MAC table2

2.0 Network Access 20% · weeks 4–5

#ObjectiveWeek
2.1Configure and verify VLANs across switches: access ports (data, voice), default VLAN, inter-VLAN connectivity4
2.2Configure and verify interswitch connectivity: trunk ports, 802.1Q, native VLAN4
2.3Configure and verify CDP and LLDP4
2.4Configure and verify L2/L3 EtherChannel (LACP)5
2.5Interpret Rapid PVST+: root bridge/port and port names, states and roles, PortFast, root guard, loop guard, BPDU filter, BPDU guard5
2.6Cisco wireless architectures and AP modes5
2.7WLAN physical connections: AP, WLC, access/trunk ports, LAG5
2.8Device management access: Telnet, SSH, HTTP/HTTPS, console, TACACS+/RADIUS, cloud managed4
2.9Interpret WLC GUI config for client connectivity: WLAN creation, security, QoS profiles, advanced settings5

3.0 IP Connectivity 25% · weeks 6–7

#ObjectiveWeek
3.1Interpret routing table: protocol code, prefix, mask, next hop, administrative distance, metric, gateway of last resort6
3.2Forwarding decision: longest prefix match, then AD, then metric6
3.3Configure and verify IPv4/IPv6 static routing: default, network, host, floating static6
3.4Configure and verify single-area OSPFv2: neighbor adjacencies, point-to-point, broadcast (DR/BDR), router ID7
3.5First hop redundancy protocols: purpose, functions, concepts7

4.0 IP Services 10% · week 8

#Objective
4.1Configure and verify inside source NAT using static and pools
4.2Configure and verify NTP client and server mode
4.3Role of DHCP and DNS
4.4Function of SNMP
4.5Syslog facilities and severity levels
4.6Configure and verify DHCP client and relay
4.7QoS per-hop behavior: classification, marking, queuing, congestion, policing, shaping
4.8Configure devices for remote access using SSH
4.9TFTP/FTP capabilities and functions

5.0 Security Fundamentals 15% · week 9

#Objective
5.1Key security concepts: threats, vulnerabilities, exploits, mitigation
5.2Security program elements: user awareness, training, physical access control
5.3Configure and verify device access control using local passwords
5.4Password policy: management, complexity, alternatives (MFA, certificates, biometrics)
5.5IPsec remote access and site-to-site VPNs
5.6Configure and verify access control lists
5.7Configure and verify L2 security: DHCP snooping, dynamic ARP inspection, port security
5.8Compare authentication, authorization, accounting
5.9Wireless security protocols: WPA, WPA2, WPA3
5.10Configure and verify WLAN in the GUI using WPA2 PSK

6.0 Automation and Programmability 10% · week 10

#Objective
6.1How automation impacts network management
6.2Traditional vs controller-based networking
6.3Controller-based SDN architecture: overlay, underlay, fabric; control/data plane separation; northbound/southbound APIs
6.4Generative and predictive AI and ML in network operations (new in v1.1)
6.5REST API characteristics: authentication types, CRUD, HTTP verbs, data encoding
6.6Configuration management: Ansible and Terraform (Terraform new in v1.1)
6.7Recognize components of JSON-encoded data

Weeks 11–12: readiness gate

  1. Boson ExSim full exam, timed. Below 75%: two more weeks on weakest domains before booking.
  2. Re-lab every bold "configure and verify" objective above from a blank topology, timed.
  3. Second ExSim at 85%+ : book Pearson VUE for the following week.
